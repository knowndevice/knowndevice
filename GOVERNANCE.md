# Governance

Known Device is maintained by Konrad Karauda. No foundation, sponsor,
company ownership, or service commitment is implied by this repository.
Contributors retain copyright in their contributions.

The maintainer sets release scope, reviews changes, and publishes decisions
in issues and RFCs. Once public, GitHub Issues tracks accepted work and
milestones; pull requests carry implementation and review. A disagreement
should include the concrete tradeoff, a proposed alternative, and evidence.
The maintainer records the decision and reason in the issue or RFC.

Regular contributors can become maintainers after sustained contributions
and review work. Changes to maintainer membership are announced in an issue
and reflected here. Maintainer access is granted only to the required
repository and release roles.

Local rotation, recovery, diagnostics, extension contracts, and conformance
remain open source. Any future hosted service is optional. Commercial
relationships that affect project decisions must be disclosed by the
people making those decisions.

Releases follow [the release process](docs/ops/release.md). Security fixes
may use a private advisory until a patch is ready. Public release notes
then describe affected versions and mitigation.
